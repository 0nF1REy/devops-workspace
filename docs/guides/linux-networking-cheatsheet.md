# 🌐 Cheatsheet de Comandos de Rede (Linux)

[← Voltar ao README](../../README.md)

| Comando      | Descrição                                                                                                                 | Exemplo de uso               |
| ------------ | ------------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| `ping`       | Testa a conectividade entre sua máquina e um servidor, medindo tempo de resposta (latência) e perda de pacotes.           | `ping -c 4 myanimelist.net`  |
| `traceroute` | Mostra o caminho que os pacotes percorrem até o destino, exibindo cada “salto” (roteador) na rede.                        | `traceroute myanimelist.net` |
| `nslookup`   | Consulta o DNS para obter o endereço IP de um domínio (ou outras informações de resolução de nomes).                      | `nslookup myanimelist.net`   |
| `dig`        | Ferramenta avançada para consultar o DNS, exibindo informações detalhadas como registros (A, MX, NS) e tempo de resposta. | `dig myanimelist.net`        |
